- **ATProto / Bluesky** — bot operations, handle verification, custom domain proofs.
- **On-device AI** — real ONNX models executed via WebAssembly in a PWA, zero data leaving the device.
- **Android & single-file tooling** — camera pipelines, local-first clients, apps that build without a heavyweight toolchain.
